# Coleta e comparação de preços

## Problema

Comparar muitos resultados de busca manualmente é repetitivo e dificulta análises históricas. O projeto explora como transformar páginas de produtos em uma tabela simples que possa ser filtrada e estudada.

## Implementação

O scraper usa Requests para buscar as páginas e BeautifulSoup para interpretar o HTML. A navegação multipágina, a extração dos campos e a geração do CSV foram separadas em módulos próprios, reduzindo o acoplamento do script principal.

O resultado é um arquivo tabular com os dados coletados, adequado para comparação ou processamento posterior.

## Limitações

Este é um projeto educacional. Seletores HTML podem mudar, preços podem depender de região ou sessão, e qualquer coleta real precisa respeitar limites de acesso e os termos do site de origem. Esses fatores tornam observabilidade, tratamento de erros e manutenção tão importantes quanto a primeira extração bem-sucedida.
