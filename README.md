# Portfólio

Portfólio pessoal construído com Astro e MDX para reunir projetos, artigos e pensamentos sobre inteligência artificial, scraping, backend e engenharia de software.

## Desenvolvimento

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

O site é publicado automaticamente no GitHub Pages a cada push para a branch `main`.
